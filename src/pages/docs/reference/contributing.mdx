## Contributing

The CCF is an open framework. Contributions to the documentation, framework model, and site code are welcome.

## Ways to Contribute

- **Content**: Add, improve, or correct documentation pages
- **Framework**: Propose extensions or refinements to the model layers
- **Code**: Improve the site layout, components, or build setup
- **Review**: Provide feedback on existing content via Issues

## Workflow

### 1. Fork & Clone

```bash
git clone https://github.com/yourusername/coherentconsciousnessframework.git
cd coherentconsciousnessframework
npm install
```

### 2. Create a Branch

```bash
git checkout -b docs/my-addition
# or
git checkout -b fix/sidebar-typo
```

### 3. Make Your Changes

- Doc pages live in `src/pages/docs/`
- Components live in `src/components/`
- Update `src/components/Sidebar.astro` if you add a new page

### 4. Submit a Pull Request

Push your branch and open a PR against `main`. Include:
- A clear title describing the change
- A short description of what was added or changed
- Any relevant context or motivation

## Content Standards

- Write in plain, precise language — avoid jargon unless defined in the Glossary
- Use sentence case for headings
- Keep paragraphs short (3–5 sentences max)
- Prefer concrete examples over abstract statements
- Add new terms to the Glossary

## Code of Conduct

This project follows a simple standard: engage with ideas, not identities. Critique frameworks, not contributors.
