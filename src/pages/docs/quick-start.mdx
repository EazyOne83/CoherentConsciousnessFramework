## Quick Start

Get the site running locally in under five minutes.

## Prerequisites

- **Node.js** ≥ 18.0.0
- **npm** ≥ 9.0.0 (or pnpm / yarn)

## Clone & Install

```bash
git clone https://github.com/yourusername/coherentconsciousnessframework.git
cd coherentconsciousnessframework
npm install
```

## Start the Dev Server

```bash
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser.

## Build for Production

```bash
npm run build
```

Output goes to `dist/`. Preview the build locally:

```bash
npm run preview
```

## Adding a New Doc Page

1. Create a new `.mdx` file inside `src/pages/docs/` (or a subfolder)
2. Add the frontmatter block:

```mdx
---
layout: ../../layouts/DocsLayout.astro
title: My New Page
description: A brief description for SEO.
---

## Your content here
```

3. Add the page to the sidebar in `src/components/Sidebar.astro`
4. Save — the dev server hot-reloads instantly

## Project Structure

```
coherentconsciousnessframework/
├── src/
│   ├── components/       # Header, Sidebar, TableOfContents
│   ├── layouts/          # DocsLayout.astro
│   ├── pages/
│   │   ├── index.astro   # Landing page
│   │   └── docs/         # All .mdx documentation pages
│   └── styles/           # global.css
├── public/               # Static assets (favicon, images)
├── astro.config.mjs      # Astro + MDX + Sitemap config
├── tsconfig.json
└── package.json
```
