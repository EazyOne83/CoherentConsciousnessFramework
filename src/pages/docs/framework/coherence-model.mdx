## The Coherence Model

The CCF formalizes coherence as a **relational property** that can be assessed, tracked, and improved. This page describes the model's structure.

## Coherence as a Triad

Any coherence state is described by three variables:

```
C(S) = f(Alignment, Signal Fidelity, Adaptive Capacity)
```

Where:
- **Alignment** — the degree to which parts share a common frame of reference or purpose
- **Signal Fidelity** — the accuracy with which information is preserved across interfaces
- **Adaptive Capacity** — the system's ability to reintegrate perturbations without losing identity

A system is highly coherent when all three are strong. Fragility arises when any single dimension is low, even if the others are high.

## Coherence States

| State | Description | Diagnostic Signal |
|---|---|---|
| **Integrated** | All three dimensions high | Smooth coordination, low friction |
| **Rigid** | High alignment, low adaptive capacity | Resistance to new information |
| **Fragmented** | Low alignment, variable fidelity | Coordination failures, conflict |
| **Noisy** | Low signal fidelity | Miscommunication, repeated clarifications |
| **Volatile** | High adaptive capacity, low alignment | Rapid change without direction |

## The Coherence Cycle

Coherence is not a destination — it is a cycle:

```
Perturbation → Sensemaking → Re-alignment → Integration → Stable State
       ↑___________________________________________________|
```

Systems that skip sensemaking (jumping directly to re-alignment) produce brittle coherence — apparent stability that fractures under the next perturbation.

## Measuring Coherence

The CCF does not prescribe a single measurement instrument. Instead, it offers **diagnostic questions** at each layer:

- **L1**: Can the individual articulate their current commitments and how they relate to action?
- **L2**: Do the parties share an interpretation of what is happening?
- **L3**: Does the group have a shared model of its own process?
- **L4**: Does the institution's formal structure reflect its actual operating norms?
